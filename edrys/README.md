# Edrys-Classrooms für die Vorlesung

Jede Sitzung hat eine Edrys-Konfiguration ([edrys-Lite](https://edrys-labs.github.io) mit dem Modul [module-liascript](https://github.com/edrys-labs/module-liascript)). Die LiaScript-Folien laufen darin mit `classroom: true`. Quiz- und Umfrageantworten aller Teilnehmenden werden synchronisiert und lassen sich vorn gemeinsam auswerten.

## Ablauf (Dozent)

1. Auf **Classroom anlegen** klicken. Edrys legt einen neuen Classroom an, der Ihrem Browser gehört.
2. **GOTO CLASSROOM** wählen und die Adresse (`https://edrys-labs.github.io/?/classroom/…`) kopieren.
3. Im Startmenü von edrys-Lite für diesen Classroom den Schreibschutz (*write protection*) setzen, damit Studierende die Konfiguration nicht ändern.
4. Den Classroom-Link an die Studierenden geben (Moodle, QR-Code auf der ersten Folie).

Wichtig: Jeder Klick auf **Classroom anlegen** erzeugt einen *neuen* Raum. Studierende bekommen deshalb nur den Classroom-Link, nie den Anlegen-Link. Der Classroom liegt im Browser, in dem er angelegt wurde – vor der Sitzung im selben Browser öffnen.
